# Wingspan · Contador (PenTech) — v1.0

Contador de puntos no oficial para Wingspan y sus expansiones (Europa, Oceanía, Asia y Américas).

## Publicar en GitHub Pages
1. Crear el repositorio (propuesta: `Wingspan-contador` en la cuenta pentech-26).
2. Subir todos los archivos de esta carpeta (salvo `icon-1024.png`, que es el máster).
3. Settings → Pages → rama `main`, carpeta raíz.
4. Dirección: https://pentech-26.github.io/Wingspan-contador/

## Cambiar algo después
- Subir siempre `CACHE` en `sw.js` (`wingspan-contador-v1` → `v2`…).
- La versión visible está en la constante `VERSION` de `index.html`.
- Licencia: objeto `LICENCIA` en `index.html` (clave, enlace de compra y partidas de prueba).

## Imagen de entrada e icono
`splash.webp` (841×1870, ilustración de Davito) es el fondo de la entrada. El icono (`icon-*.png`, máster en `icon-1024.png`) también es arte de Davito.

## Tipografías
